# Dragon Ball Mod

Dragon Ball Mod is a Minecraft mod that adds Dragon Ball transformations, hairstyles, and structures. This mod includes various transformations such as Kaioken, Super Saiyan, Super Saiyan Blue, Super Saiyan God, and Super Saiyan Rose. It also features different hairstyles and structures inspired by the Dragon Ball universe.

## Install

1. Download the mod from the [GitHub repository](https://github.com/EnderDevelopment/DragonBallMod).
2. Place the downloaded `.jar` file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric loader installed.

## Use

1. Launch Minecraft with the mod installed.
2. Use the in-game UI to select and apply different transformations, hairstyles, and structures.
